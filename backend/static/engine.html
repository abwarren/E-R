Hands & Board

One hand per line. Last line = board (leave blank for random). Supports PLO4, PLO5, PLO6.

API Access

curl -X POST http://localhost:4002/api/run \
  -H "Content-Type: application/json" \
  -d '{
    "variant": "plo4-6max",
    "hands": ["AhKhQhJh","AdKdQdJd"],
    "board": "",
    "samples": 2000
  }'

# Poll results:
curl http://localhost:4002/api/results/<run_id>
